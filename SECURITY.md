# Security Policy

## Reporting a vulnerability

Please report security issues to https://github.com/waqar2403/honeycomb-sdk/security/advisories/new.

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/waqar2403/honeycomb-sdk/issues

## Scope

This policy applies to the generated Muhammad Waqar SDK packages published from this
repository (npm, PyPI, Packagist, RubyGems, LuaRocks, and the Go module).

This is an unofficial SDK for the Honeycomb public API, generated by
Muhammad Waqar. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
